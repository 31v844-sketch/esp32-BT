雙雲台四舵機系統與重心計算導覽

1. 雙雲台 4 顆伺服舵機串聯機構
右側機械尾巴由兩組 2 軸雲台組成：基座雲台（Servo #1 水平 + Servo #2 垂直）負責帶動整條力臂；中段雲台（Servo #3 水平 + Servo #4 垂直）串聯於中段關節，提供二次彎曲增益，能以更小的基座空間產生更大的重心牽引力矩。
2. 0.1° 精細角度微調
除了使用 WASD 連續擺動外，按住 Shift + WASD 可進入慢速精準模式，或直接點擊滑桿兩側的 -0.5° / +0.5° 按鈕逐格觀察重心偏移變化。
3. 即時重心位置 (CoM) 投影與計算過程
觀察左側人物身上的綠色質心球以及地板上的重心投影光圈與偏移線。左下角儀表板會即時列出質心 3D 座標 $(X, Y, Z)$、尾巴力矩 $\tau_{\text{tail}}$、身體回復力矩與傾倒裕度。
