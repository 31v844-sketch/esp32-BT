重心平衡機械尾巴系統

1. 人物姿態控制
2. 人物體型參數 (影響模型與慣性力矩)
3. 機械尾巴機構參數
系統狀態：待機靜止 (重心置中)
舵機輸出 -> 水平: 90° | 垂直: 90°
全方向觀察視角 (可滑鼠拖曳/滾輪縮放)

系統使用導覽與物理模擬說明

步驟 1：全方向 3D 觀察
使用右上角的「正面 / 背面 / 左側 / 右側 / 俯視」按鈕一鍵切換視角，或直接按住滑鼠左鍵拖曳旋轉、滾輪縮放鏡頭。
步驟 2：調整身高與體重模型
拖動「人物身高」與「人物體重」滑桿，左側 3D 模型體型與綠色重心球體會即時變化。身高越高或體重越重，傾倒時產生的力矩越大，尾巴會自動加快反應速度並加大甩動幅度。
步驟 3：控制機械尾巴伸縮
調整「尾巴伸縮長度（30% ~ 150%）」可將右側機械尾巴收短或放長。放長時力臂增加，可用較小角度平衡重心；收短時則需要更大的擺動角度補償。
步驟 4：同步 ESP32-C3 實體硬體
點擊「連線 ESP32-C3」配對藍牙裝置（ESP32_Web_Controller），計算出的「水平角度,垂直角度」會即時傳送給實體舵機。
